# Digital_Logic_Lab_final_project

### 數位邏輯實驗專題：有號數四則運算機 (FPGA)
本專題為基於 Xilinx Artix-7 (EGO1 開發板) 實作之硬體計算機。支援 4-bit 帶號數 (-7 到 +7) 的加、減、乘、除運算。具備十字方向鍵輸入介面、動態浮動正負號顯示、硬體防殘影、動態零消隱，以及除零防呆機制。

## **模組功能**

- **`top.v` (頂層主控模組與狀態機)**
    - **功能**：系統的中樞神經。內建單線程狀態機 (FSM)，負責協調各模組的運作時序。
    - **硬體細節**：統一處理十字游標移動與數字修改。在按下執行鍵後，控制螢幕全暗 0.15 秒進行過渡動畫，並處理除以零的防呆機制。負責實例化 ALU 與顯示模組。

- **`debounce.v` (按鍵防彈跳模組)**
    - **硬體細節**：利用取樣計數器延遲 10ms，確認訊號穩定後，透過邊緣偵測 (Edge Detection) 產生單一週期的乾淨脈衝 (Pulse)，確保十字按鍵與執行鍵不會連續觸發。

- **`alu_core.v` (算術邏輯單元與 BCD 轉換)**
    - **功能**：負責執行加、減、乘、除核心運算，並內建順序型 BCD 轉換引擎。
    - **硬體細節**：
        - **除法精度擴展與修正**：解決 Verilog 底層有號數除法異常，採用先取絕對值相除、再補回正負號的演算法。除法運算內部自動放大 1000 倍，提供高達 3 位小數的精確度。
        - **順序型 BCD (Sequential BCD)**：為避免組合邏輯延遲導致的亂碼，採用 20 個 Clock 週期的 Shift-and-Add-3 演算法，確保轉換 100% 穩定。
        - **浮動正負號引擎**：動態偵測運算結果位數，將負號精準定位在數字最高位的正左側一格。

- **`seg_display.v` (七段顯示器掃描模組)**
    - **動態掃描 (Dynamic Scanning)**：降頻掃描，利用視覺暫留輪流點亮 8 顆顯示器。內建符合 EGO1 開發板的 Active-High 解碼表 (1 為亮，0 為暗)。
    - **動態零消隱 (Dynamic Zero-Blanking)**：智慧判斷輸入與結果的位數，若高位數為 0 則自動熄滅不顯示（例如 `007` 會自動顯示為 `  7`）。
    - **硬體防殘影 (Hardware Blanking)**：在位數切換的過渡期間強制熄滅顯示器，徹底消除視覺鬼影。

## **操作指南**

將程式燒錄至 EGO1 開發板後，請依照以下步驟操作：

### 1. 系統初始化

- **重置 (Reset)**：按下板子左下方的 **S6 鍵 (`rst_n`)**。
- **狀態**：系統進入輸入模式，左半部螢幕亮起，預設顯示游標閃爍。

### 2. 設定運算參數 (十字鍵 + 指撥開關)

- **選擇運算碼 (聯集防呆開關)**：
    - `SW7` 或 `SW6`：加法 (+)
    - `SW5` 或 `SW4`：減法 (-)
    - `SW3` 或 `SW2`：乘法 (*)
    - `SW1` 或 `SW0`：除法 (/)
    > *防呆機制：若同時撥上兩種以上的運算開關，或全部沒撥，系統將拒絕計算並顯示 `E`。*

- **設定雙輸入數值 (十字方向鍵，S0~S4)**：
    - **S3 (左鍵)** / **S0 (右鍵)**：左右移動閃爍游標，在 8 個輸入格 (A 與 B 的正負號及數字) 之間切換。
    - **S4 (上鍵)** / **S1 (下鍵)**：
        - 若游標在**數字位**：按一下 +1 或 -1 (滿 9 歸零，0 減 1 變 9)。
        - 若游標在**符號位**：切換正號 (空白) 與負號 (`-`)。

> *Tip: 左半部 4 格為輸入 A (符號+3位數字)，右半部 4 格為輸入 B (符號+3位數字)。前綴多餘的 0 系統會自動隱藏，維持畫面乾淨。*

### 3. 執行運算

- **確認輸入**：設定完開關與數字後，按下十字鍵正中央的 **S2 鍵 (`btn_exec`)**。
- **顯示結果**：
    - 螢幕瞬間**全暗 0.15 秒** (過渡動畫)，隨後左半部螢幕熄滅。
    - 右半部螢幕亮起正確的運算結果，負號會自動緊貼在數字最前方。
    - **動態小數點**：加減乘法保留 1 位小數；除法會自動擴充為 **3 位小數** (例如 7 / 4 顯示 1.750)。
    - **除以零防護**：若輸入 `X / 0`，螢幕會啟動防護機制，最右側顯示 `E`。

### 4. 進行下一次運算

- 再次按下中央 **S2 鍵**，系統重回等待輸入狀態，即可設定下一組數字 (游標重新出現)。
