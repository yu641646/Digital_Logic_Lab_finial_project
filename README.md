# Digital_Logic_Lab_finial_project
數位邏輯實驗專題：有號數四則運算機 (FPGA)。本專題為基於 Xilinx Artix-7 (EGO1 開發板) 實作之硬體計算機。支援 2 位數帶號數 (-99 到 +99) 的加、減、乘、除運算。具十字按鍵輸入介面、動態掃描同步顯示，以及硬體防呆機制。

### 模組功能

- **`calculator_top.v` (頂層模組)**
    - **功能**：內建兩段式狀態機 (FSM)，負責切換「等待輸入」與「顯示結果」狀態。負責實例化所有子模組並串接 15-bit 的寬資料流。
- **`debounce.v` (按鍵防彈跳模組)**
    - **硬體細節**：使用雙層 D Flip-Flop 消除亞穩態，並透過 21-bit 計數器延遲 20ms，最後邊緣偵測輸出乾淨的單步脈衝。
- **`bcd_counter.v` & `bcd_to_bin.v` (十進位輸入引擎)**
    - **功能**：處理使用者透過方向鍵輸入的 0~9 數字，並透過硬體乘法器 `(十位數 * 10 + 個位數)` 將 BCD 碼無縫轉換為 ALU 所需的 8-bit 有號二進位數。
- **`alu.v` (算術邏輯單元)**
    - **硬體細節**：處理兩個 8-bit 帶號數 (-99 ~ +99) 的運算。為防止乘法溢位，輸出擴展為 **15-bit** 帶號數 (支援極值 +9801)。內建除以零防護機制。*(註：除法運算在硬體層級採無條件捨去小數點)*。
- **`bcd_converter.v` (二進位轉 BCD 模組)**
    - **功能**：使用純組合邏輯實現 Double Dabble 演算法。
    - **硬體細節**：擴增為 15 次迴圈展開，將 15-bit 二進位絕對值轉換為千、百、十、個位數 BCD 碼，避免使用極度消耗硬體資源的除法器。
- **`seg_display.v` (七段顯示器掃描模組)**
    - **動態掃描 (Dynamic Scanning)**：降頻至約 760Hz，利用視覺暫留輪流點亮 8 顆顯示器。
    - **零消隱 (Zero-Blanking)**：高位數若為 0 則自動熄滅不顯示（如 5 不會顯示為 0005）。


## **操作指南**

  將程式燒錄至 EGO1 開發板後，請依照以下步驟操作：

### 1. 系統初始化

- **重置 (Reset)**：按下板子最左下角的 **S6 鍵 (`rst_n`)**。
- **狀態**：系統進入輸入模式，螢幕即時顯示預設值 `[0 0] [0 0]`。

### 2. 設定運算參數 (動態按鍵 + 指撥開關)

系統設計：

- **設定正負號與運算碼 (靜態開關)**：
    - `S1 ~ SW0`：運算碼 OP (`00`=加, `10`=減, `01`=乘, `11`=除)
    - `SW2`：數字 B 的正負號 (往上撥為負)
    - `SW3`：數字 A 的正負號 (往上撥為負)
- **設定數字 (十字方向鍵，按一下 +1，滿 9 歸零)**：
    - **S4 (上鍵)**：A 的十位數
    - **S2 (下鍵)**：A 的個位數
    - **S3 (左鍵)**：B 的十位數
    - **S0 (右鍵)**：B 的個位數

> *Tip: 操作十字鍵時，左側 8 碼螢幕會「即時」追蹤並顯示設定的 A 與 B 雙位數值與符號。*
> 

### 3. 執行運算

- **確認輸入**：按下十字鍵正中央的 **S1 鍵 (`btn_center`)**。
- **顯示結果**：
    - 左側螢幕數值會被鎖定（此時按鍵與開關無效）。
    - 螢幕靠右對齊亮起，顯示正確的運算結果（最高支援到千位數與負號顯示）。
    - **除以零防護**：若輸入 `X / 0`，螢幕會啟動防護機制，顯示 `EEE`。

### 4. 進行下一次運算

- 再次按下中央 **S1 鍵**，系統重回等待輸入狀態，即可設定下一組數字(按Reset也行)。
